Photo by Kelli McClintock on Unsplash In this article, I will show you how you can bundle your Moleculer-based microservices project into an executable with pkg . Why do we want to bundle a microservices project? Making a commercial application which is executed on-premise without source code Deploy it as a single file; no need to install Node.js, npm, and download millions of files via npm install Minimizing the Docker image size …just for fun :) Create a sample project To generate a Moleculer microservice project, I’m using the official “ project ” template with Moleculer CLI .
